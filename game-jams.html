GAME JAMS

Learn about GDK's hosted game jams

What is a game jam?

A game jam is a small event where game developers get together to create a game from scratch within a short time frame (usually 48-72 hours) based on a surprise theme.

GDK hosts 1-2 game jams every semester. Our jams are typically 48-72 hours, though occasionally we host week-long game jams. People can participate solo or in a team.

Game jams are a great opportunity to learn a lot about all aspects of game development in a very short time period and are open to ALL experience levels.

See our itch.io page to look at previous game jams!

VIEW OUR ITCH.IO

How to participate

We typically announce upcoming game jams on our main Discord server about a month or so in advance to give people time to prepare. We host our game jams on a seperate Discord server, to allow people to form teams and look for members. It is also where we stream the kick-off and showcase.

There is no official site for registering your team, all you have to do is participate in the jam and submit your game on the itch.io page that we will share in the game jam discord server! Only ONE person from each team needs to "sign-up" for the game jam on the itch page.

Format

1. Join the server and form a team

Join our game jam server mentioned above and find people to team up with IRL or via the server. Discuss with engine you will use, and what roles everyone wants to have. You can also brainstorm potential game ideas (just don't start before kick-off).

2. Kick off

During an in-person game jam, GDK officers will give a brief presentation of the event and go over the schedule for the weekend.
During an online jam, this will usually occur over Discord. Keep an eye out for any invites!

3. Theme Reveal

At the end of the Kick-Off presentation the GDK officers will reveal the theme for the jam. This is meant to inspire creativity in project planning and team collaboration but it is not required to rigidly apply the theme to your project. This event is about learning more than anything else!

4. Jamming Begins!

Once the teams are formed and the theme is revealed, development is a go! Now is the time to scope out the game, split up tasks, and get creating!

Resources for Beginners

No prior experience is required to participate in game jams (seriously).

However, it is best to get a game engine or tools downloaded prior to the start of the game jam so you can get right into game creating! For beginners, we recommend using Unity as your game engine but it is not required to use Unity, you can use any game engine you want during the jam.

We'd suggest watching a few tutorials before the jam starts, so that you aren't too overwhelmed once things get started.

  • First Time Jammer Guide
  • Unity Essentials Guide
  • Setting up version control for Unity
  • Blender Tutorial (3D Modeling)
  • Maya Tutorial (3D Modeling) -- Digital Media and Emerging Media students have access to a free educational license for Maya
  • Aesprite Tutorial (Pixel Art)
